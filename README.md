
# 🎓 Student Grade Tracker (GUI Version)

## 📌 Internship Task - CodeAlpha

This project is developed as part of the CodeAlpha Java Internship.

## 💡 Project Description
The Student Grade Tracker is a Java GUI application built using Swing.
It allows users to:
- Add student names
- Enter grades (comma separated)
- Calculate average score
- Find highest score
- Find lowest score
- Display summary report

## 🛠 Technologies Used
- Java
- Swing (GUI)
- ArrayList
- OOP Concepts

## ▶ How to Run
Compile:
javac StudentGradeTrackerGUI.java

Run:
java StudentGradeTrackerGUI
